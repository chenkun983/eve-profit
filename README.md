# EVE 制造利润分析器

> EVE Online 国服（晨曦）制造利润分析工具，支持实时市场行情、制造利润计算、利润排行、用户关注清单。

## 功能总览

### ✅ 已实现

| 功能 | 说明 |
|------|------|
| **物品分类浏览** | 2000+ 市场分类树，中文翻译，手机端响应式 |
| **中文搜索** | 按中文名搜索任何物品 |
| **吉他市场行情** | 最低卖单价、最高买单价、买卖价差、多时段去极值加权均价 |
| **制造利润计算** | 5 种模式：蓝图零售、基础零售、收单、蓝图批发、基础批发 |
| **材料逐项定价** | 每样材料可独立选 收单/卖单/自产，支持比率（80%-100%） |
| **全量材料追溯** | 递归分解至基础矿物/终端物料 |
| **多时段均价表** | 24h / 3d / 7d / 30d / 90d 去极值加权均价 + 7d-90d 趋势 |
| **用户系统** | 注册/登录/注销/修改密码/邮箱，首个用户自动为管理员 |
| **关注清单** | 登录后可添加/移除关注物品，保存材料定价配置 |
| **利润排行** | 6 种利润标签（倒卖/蓝图零售/基础零售/收单/蓝图批发/基础批发），可点击排序 |
| **分类扫描排行** | 按一级分类扫描，24h 缓存 |
| **批发折扣** | 全局折扣 80%-100% 可配置，可保存 |
| **管理后台** | 会员管理、SDE 版本信息、管理员设置 |
| **SDE 自动更新** | 管理员可在线触发 SDE 更新 |
| **V2Ray 代理** | 服务器端 SDE 下载走代理 |
| **GitHub Webhook** | 自动部署（可选） |
| **每日定时缓存** | cron 每天 11:00 自动扫描主要分类 |
| **响应式布局** | 桌面/手机自适应 |

# 启动

## 利润计算说明

### 三种制造模式

| 模式 | 材料定价 | 成品定价 | 说明 |
|------|----------|----------|------|
| 理想利润 | 收单价 | 卖单价 | 最乐观，挂单收材料+挂单卖成品 |
| 实时利润 | 卖单价 | 卖单价 | 最真实，秒买材料+挂单卖成品 |
| 保守利润 | 卖单价 | 收单价 | 最悲观，秒买材料+秒出成品 |

### 倒卖利润（排行专用）

挂单费率 0.75% + 销售税 1%，按当前最低卖价买入、最高收价卖出。

### 成本公式

```
效率因子 = 1 / (1 + 建筑效率 + 蓝图ME × 0.01)
有效材料成本 = 基础材料成本 × 效率因子
星系成本 = 有效材料成本 × 星系成本指数
设施税 = 有效材料成本 × 设施税率
总成本 = 有效材料成本 + 星系成本 + 设施税

时间效率 = 蓝图TE × 0.02
有效时间 = 基础制造时间 / (1 + 时间效率)
```

## API 接口

| 路径 | 说明 | 需登录 |
|------|------|--------|
| `GET /` | 主页面 | 否 |
| `GET /api/status` | SDE 状态 | 否 |
| `GET /api/search` | 搜索物品 | 否 |
| `GET /api/price` | 市场价格行情 | 否 |
| `GET /api/calculate` | 利润计算 | 否 |
| `GET /api/categories` | 分类树 | 否 |
| `GET /api/items-by-category` | 分类下物品 | 否 |
| `POST /api/auth/register` | 注册 | - |
| `POST /api/auth/login` | 登录 | - |
| `GET /api/auth/status` | 登录状态 | 否 |
| `GET /api/watchlist` | 关注清单 | 是 |
| `POST /api/watchlist/add` | 添加关注 | 是 |
| `POST /api/watchlist/remove` | 移除关注 | 是 |
| `GET /api/ranking/category` | 分类利润排行 | 是 |
| `GET /api/ranking/watchlist` | 关注清单排行 | 是 |
| `POST /api/sde/update` | 更新 SDE | 管理员 |
