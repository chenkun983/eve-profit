# EVE国服工业订单系统

> EVE Online 国服（晨曦）工业管理 + 订单协作平台，支持市场行情、制造利润计算、多用户订单系统、工业产线管理。

## 功能总览

### ✅ 已实现

| 功能 | 说明 |
|------|------|
| **物品分类浏览** | 2000+ 市场分类树，中文翻译，手机端响应式 |
| **中文搜索** | 按中文名搜索任何物品 |
| **吉他市场行情** | 最低卖单价、最高买单价、买卖价差、多时段去极值加权均价 |

## 订单系统流程

### 采购单
```
发单 → 订单池公开 → 制造商接单（制作中）→ 制造商交付（待验收）→ 下单人确认（已完成）
                                                                   └─ 5天自动确认
```

### 出售单
```
发单 → 订单池公开 → 任意用户接单（待交货）→ 卖家交货（待确认）→ 买家确认（已完成）
                                                                   └─ 3天自动确认
```

## 利润计算说明

### 成本公式

```
效率因子 = 1 / (1 + 建筑效率 + 蓝图ME × 0.01)
有效材料成本 = 基础材料成本 × 效率因子
星系成本 = 有效材料成本 × 星系成本指数
设施税 = 有效材料成本 × 设施税率
总成本 = 有效材料成本 + 星系成本 + 设施税
```
